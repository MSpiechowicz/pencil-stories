Paper Stack

Old sheets land on a walnut desk, one sentence per sheet, and every sheet moves differently. It reads like the documents of a real life, and each sheet becomes a natural caption beat.

Motion vocabulary

  • 0:00Drop & settle with spring overshoot, then the line types itself out
  • 0:03Flip up from below (rotateX) and the “LAID OFF” stamp slams with a camera shake
  • 0:05Crumple and toss: the sheet collapses into a paper ball and flies off frame
  • 0:07Fold-open on a top hinge, then the checklist of worries writes in
  • 0:10Torn strip slides in, red pen strikes “only one”, writes “you’re not.”
  • 0:12A child’s crayon drawing floats up and draws itself: home, sun, two people, a heart

// One <Sequence> per sheet; each sheet owns its motion.
const Notice = () => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const enter = spring({ frame, fps, config: { damping: 15, stiffness: 110 } });
  const stamp = interpolate(frame, [32, 38], [2.6, 1], {
    extrapolateLeft: 'clamp', extrapolateRight: 'clamp', easing: Easing.in(Easing.cubic) });
  return (
    <AbsoluteFill style={{ perspective: 1600 }}>
      <Img src={staticFile('paper/notice.jpg')} style={{
        transform: `translateY(${(1 - enter) * 140}%) rotateX(${(1 - enter) * 65}deg) rotate(3deg)` }} />
      <Stamp scale={stamp} />
    </AbsoluteFill>);
};

Remotion sketch 
const FallingLetter = ({ char, i }) => {
  const frame = useCurrentFrame();
  const start = 140 + Math.floor(random(`fall-${i}`) * 30);  // deterministic
  const t = Math.max(0, frame - start);
  const y = 0.5 * 9.8 * t * t / 6;                             // px, gravity
  const rot = (random(`dir-${i}`) > 0.5 ? 1 : -1) * t * 2.2;
  return <span style={{ display: 'inline-block',
    transform: `translateY(${y}px) rotate(${rot}deg)` }}>{char}</span>;
};

Publishing checklist

  1. Render one master MP4; upload the same file to Shorts and Reels.
  2. Never re-upload a file with another app’s watermark; Instagram ranks it lower.
  3. Use music from the YouTube Audio Library or Instagram’s in-app library. A copyrighted track can block monetization on that Short.
  4. Burn captions into the video and keep them out of the bottom 22% and the right 14%.
  5. Post at the same time daily for the first 30 days so you learn what holds attention.

Monetization: to join the YouTube Partner Program with Shorts, a channel needs 1,000 subscribers plus 10 million valid public Shorts views in 90 days (or 4,000 public watch hours on long videos in 12 months). Check the current numbers in YouTube Studio → Earn before you plan around them. Treat Instagram mainly as audience growth that sends people to the channel. A clear, repeatable style like Paper Stack helps here because viewers recognise your Shorts in the feed before they read a word.
